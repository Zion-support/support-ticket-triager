## What it does

Support Ticket Triager reads every incoming ticket, classifies intent and urgency, detects sentiment, and routes it to the right queue with a suggested first response — cutting first-response time by 60%+.

## Key features

- **Intent & urgency classification** — billing, bug, how-to, outage — auto-tagged.
- **Sentiment-aware prioritization** — frustrated VIPs jump the queue.
- **Smart routing** — skills-based assignment with load balancing.
- **Suggested replies** — first draft pulled from docs and past resolutions.
- **Duplicate clustering** — incident spikes grouped into one parent ticket.

## Who it's for

Support teams handling 500+ tickets/month across email, chat, and portals.
